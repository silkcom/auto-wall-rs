# Dungeon-map detection

Extracting walls, doors, and lights from battle-map images for virtual tabletops.

## Language

**Wall**:
A boundary that blocks line of sight on a map.

**Door**:
An opening with a movable barrier, represented separately from permanent walls.

**Light**:
A map light source with a position and illumination properties.

**Grid size**:
The number of image pixels corresponding to one map grid unit.

**UVTT data**:
A Universal VTT map description containing map dimensions, line-of-sight boundaries, portals, and lights, with an optional embedded image.
